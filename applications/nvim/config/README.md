# Design Principles

Atelier is a collection of carefully designed development tools and configurations. Every decision favors clarity, intentionality, and long-term maintainability.

- Every line of configuration expresses a deliberate decision.
- Native extension points come before custom configuration.
- Responsibilities come before tools.
- Adapt the environment before adapting the application.
- Visual consistency reduces cognitive load.
- Defaults are trusted until there's a reason to change them.
- Understand before configure.
