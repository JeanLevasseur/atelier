# ADR 0001 — Foundational Principles

## Status

Accepted

## Context

Atelier is designed as a long-lived working environment.

## Decision

The project is guided by the following foundational principles:

- Tools exist to support the work.
- Understand before automating. Automation should remove repetitive work, not replace understanding.
- Prefer established standards.
- Favor structural simplicity.
- Every dependency must resolve an observed friction.
- The environment evolves incrementally.

## Consequences

New tools, dependencies, and configuration are introduced only when they address a clearly identified need.
